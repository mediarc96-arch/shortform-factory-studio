# malmoelab-ko-repeat-jeonyeok-004-grok-build

- 작업 유형: `review_fix_build`
- 시리즈: `malmoelab-hangul-repeat`
- 포맷: **41~42초 빈칸+따라하기 (16:9 가로, 오프닝/엔딩 포함)**
- 버전: **v3 review fix**

---

## 이번 수정의 핵심

- 오프닝은 `characters/daehan/01_Opening_clean.mp4`를 고정 템플릿으로 사용
- `question`, `thinking`, `answer`, `repeat`는 `003-grok-build`의 승인 가능한 Grok 씬을 재사용
- 엔딩은 생성형 Grok 클립 대신 `characters/daehan/02_Ending.mp4` 고정 템플릿으로 회귀
- 반복 파트는 **따라 말할 수 있을 정도로 간격을 넓혀 재타이밍**
- 한국어 나레이션은 **세그먼트별 음량 정규화**를 적용해 단어마다 소리 크기가 튀지 않게 맞춤
- 나레이션은 **남성 목소리만** 사용
- 본편 텍스트는 카드 UI가 아니라 **칠판 위 분필 합성**으로만 처리
- 전체 구성은 **오프닝 6초 + 본편 약 31~32초 + 엔딩 4.2초**

---

## 영상 구조

```text
[오프닝]  0~6초    고정 템플릿 (01_Opening_clean.mp4)
  ↓
[씬 1]    6~12초   문제 제시
[씬 2]   12~15.2초 생각 대기
[씬 3]   15.2~21.2초 정답 공개 + 완성 문장
[씬 4]   21.2~37.6초 따라하기 (3단어 × 2회, 느린 템포)
  ↓
[엔딩]   37.6~41.8초 고정 템플릿 (02_Ending.mp4)
```

총 길이: **약 41.8초**

---

## 캐릭터 / 구도 규칙

> ⚠️ 선생님은 항상 칠판 **앞(IN FRONT OF)** 에 있어야 한다.

- 선생님 위치: 오른쪽 30~35%
- 칠판 위치: 왼쪽 65~70%
- 카메라: eye-level, waist-up medium shot
- 본편 장면에서 선생님은 칠판을 가리키거나 따라하기 제스처를 해야 한다
- 텍스트는 모두 칠판 위에만 합성한다

---

## 나레이션 규칙

> ⚠️ 이번 버전은 **한국어 남성 음성만** 사용한다.

- 한국어: 차분한 한국 남성
- 영어: 화면 표시만
- 말 속도: `01_Opening_clean`과 동일한 자연스러운 속도
- 반복 구간은 기존 003-grok-build보다 명확히 느리게
- 영어 TTS는 사용하지 않음
- 로마자는 화면에만 표시하고 TTS로 읽지 않음

---

## 오버레이 규칙

- 하단 패널/푸터 카드 금지
- 칠판 위 분필 느낌의 텍스트만 사용
- 문제 문장, 로마자, 영어, 보기 모두 칠판 영역 안에서만 표시
- 정답 장면의 강조는 보라색 포인트만 사용하고, 화면 전체 조명 톤은 바꾸지 않음
- CTA는 엔딩에서만 작게 사용

## QA 체크리스트

- [ ] 오프닝 자막이 최종본에 보이지 않음
- [ ] 엔딩은 고개 숙여 인사하는 템플릿 클립 사용
- [ ] 문제/보기 텍스트가 칠판 위에 자연스럽게 보임
- [ ] 선생님 모습이 오프닝부터 엔딩까지 동일하게 유지됨
- [ ] 본편은 남성 목소리만 사용
- [ ] 질문 구간 속도가 오프닝과 비슷하게 자연스러움
- [ ] 짧은 단어 TTS(`집`, `회사`, `화장실`)가 문장 TTS보다 유난히 크거나 작지 않음
- [ ] 정답/문장/반복/엔딩의 음성이 서로 겹치지 않음
- [ ] 반복 파트가 끝난 뒤에만 엔딩이 시작됨
- [ ] 정답 장면에서 갑작스러운 노란 조명 점프가 없음
- [ ] 생각 대기 장면에서 칠판에 `또깍 또깍 또깍` 텍스트가 보이지 않음
- [ ] 반복 구간에서 각 단어가 최소 2초 이상 유지되어 따라 말할 시간이 있음
- [ ] 엔딩 직전 프레임에서도 대한의 얼굴/갓/실루엣이 깨지지 않음
- [ ] 전체 길이가 41~42초 안에 들어옴
