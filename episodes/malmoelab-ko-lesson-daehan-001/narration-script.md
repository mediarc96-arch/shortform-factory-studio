# Narration Script — malmoelab-ko-lesson-daehan-001

## Core Rules

1. This follows the `daehan-pilot-codex-003` spoken structure by default.
2. Opening line keeps the same sentence structure as `003` and only swaps the character name.
3. Ending line keeps the same sentence structure as `003` unless the brief explicitly overrides it.
4. English prompt and CTA stay as typography overlays. Reveal copy is prepared for repurposing, not as a default spoken line in this lesson format.
5. Romanization is support text only. Do not read it out loud.
6. Spoken Korean should stay bright, clear, and learner-friendly.
7. Voice inherits from `characters/daehan/voice.json`. No episode-level override is requested.
8. Scene-4 is a recall check, not a blind quiz twist.
