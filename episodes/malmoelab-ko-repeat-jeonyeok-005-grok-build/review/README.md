# Review Guide

Use the contact sheets for quick visual review, then use `scene-ranges.csv` and `frame-map.csv` to point to exact frames.

## Files
- `contact-sheets/overview.jpg`: full-video overview
- `contact-sheets/scene-*.jpg`: 9-frame grid per scene
- `scene-ranges.csv`: scene-to-frame ranges
- `frame-map.csv`: exact frame index to timestamp and scene

## How To Report
Use this format:

`scene-3-answer / frame 492 / text too high on chalkboard`

or

`00:16.400 / scene-3-answer / teacher hand should point more right`
