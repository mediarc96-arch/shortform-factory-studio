# malmoelab-ko-repeat-jeonyeok-003

- 작업 유형: `new_episode`
- 시리즈: `malmoelab-hangul-repeat`
- 포맷: **37~38초 빈칸+따라하기 (16:9 가로, 오프닝/엔딩 포함)**
- 버전: **v3 revised**

---

## 이번 수정의 핵심

- 오프닝은 `characters/daehan/01_Opening_clean.mp4`를 고정 템플릿으로 사용
- 엔딩은 `characters/daehan/02_Ending.mp4`를 고정 템플릿으로 사용
- 오프닝 자막은 제거된 clean clip만 사용
- 나레이션은 **남성 목소리만** 사용
- 본편 텍스트는 카드 UI가 아니라 **칠판 위 분필 합성**으로만 처리
- 전체 구성은 **오프닝 6초 + 본편 약 27~28초 + 엔딩 4.2초**

---

## 영상 구조

```text
[오프닝]  0~6초    고정 템플릿 (01_Opening_clean.mp4)
  ↓
[씬 1]    6~12초   문제 제시
[씬 2]   12~15.2초 생각 대기
[씬 3]   15.2~21.2초 정답 공개 + 완성 문장
[씬 4]   21.2~33.4초 따라하기 (3단어 × 2회)
  ↓
[엔딩]   33.4~37.6초 고정 템플릿 (02_Ending.mp4)
```

총 길이: **약 37.6초**

---

## 캐릭터 / 구도 규칙

> ⚠️ 선생님은 항상 칠판 **앞(IN FRONT OF)** 에 있어야 한다.

- 선생님 위치: 오른쪽 30~35%
- 칠판 위치: 왼쪽 65~70%
- 카메라: eye-level, waist-up medium shot
- 본편 장면에서 선생님은 칠판을 가리키거나 따라하기 제스처를 해야 한다
- 텍스트는 모두 칠판 위에만 합성한다

---

## 나레이션 규칙

> ⚠️ 이번 버전은 **한국어 남성 음성만** 사용한다.

- 한국어: 차분한 한국 남성
- 영어: 화면 표시만
- 말 속도: `01_Opening_clean`과 동일한 자연스러운 속도
- 질문 구간은 기존보다 약간 빠르게
- 영어 TTS는 사용하지 않음
- 로마자는 화면에만 표시하고 TTS로 읽지 않음

---

## 오버레이 규칙

- 하단 패널/푸터 카드 금지
- 칠판 위 분필 느낌의 텍스트만 사용
- 문제 문장, 로마자, 영어, 보기 모두 칠판 영역 안에서만 표시
- 정답 장면의 강조는 보라색 포인트만 사용하고, 화면 전체 조명 톤은 바꾸지 않음
- CTA는 엔딩에서만 작게 사용

---

## QA 체크리스트

- [ ] 오프닝 자막이 최종본에 보이지 않음
- [ ] 엔딩은 고개 숙여 인사하는 템플릿 클립 사용
- [ ] 문제/보기 텍스트가 칠판 위에 자연스럽게 보임
- [ ] 선생님 모습이 오프닝부터 엔딩까지 동일하게 유지됨
- [ ] 본편은 남성 목소리만 사용
- [ ] 질문 구간 속도가 오프닝과 비슷하게 자연스러움
- [ ] 정답/문장/반복/엔딩의 음성이 서로 겹치지 않음
- [ ] 반복 파트가 끝난 뒤에만 엔딩이 시작됨
- [ ] 정답 장면에서 갑작스러운 노란 조명 점프가 없음
- [ ] 생각 대기 장면에서 칠판에 `또깍 또깍 또깍` 텍스트가 보이지 않음
- [ ] 전체 길이가 37~38초 안에 들어옴
