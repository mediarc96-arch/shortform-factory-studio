# 나레이션 스크립트 — malmoelab-ko-repeat-jeonyeok-003

## ⚠️ 핵심 규칙

1. **한국어 나레이션과 영어 나레이션은 절대 동시 재생 금지.** 순차 재생만 허용.
2. **로마자(Jip, Hoesa, Hwajangsil)는 TTS로 읽지 않음.** 화면에 텍스트로만 표시.
3. 각 세그먼트 사이 최소 0.3초 간격 유지.

## 성우 / TTS

| 트랙 | 조건 | 속도 |
|------|------|------|
| 🇰🇷 KO | 차분한 한국 남성 ("대한") | 0.75× |
| 🇺🇸 EN | 영어권 여성 | 0.85× |

---

## [오프닝] 0~7초 — 고정 클립

```
🇰🇷 KO: "안녕하세요. 여러분과 한글 공부를 같이 할 대한입니다."
(자막 없음. 영상에 내장된 나레이션.)
```

---

## [씬 1] 7~10초 — 문제 제시

```
🇰🇷 KO: "저녁에는…"
[1초 정지]
🇰🇷 KO: "…에서 쉽니다."
[0.5초 간격]
🇺🇸 EN: "I relax at…"
[1초 정지]
🇺🇸 EN: "…in the Evening."
```

> 화면: 한국어 + 로마자 + 영어 동시 표시.  
> 오디오: 한국어 전체 종료 후 → 영어 시작.

---

## [씬 2] 10~15초 — 생각 대기

```
(나레이션 없음)
🎵 SFX: 또깍 또깍 또깍
```

---

## [씬 3] 15~20초 — 정답 공개

```
🎵 SFX: 또로롱~ (1초)
[1초 간격]
🇰🇷 KO: "정답은 집입니다."
[0.5초 간격]
🇺🇸 EN: "The answer is house."
```

> 효과음 완료 → 한국어 → 간격 → 영어. 겹침 금지.

---

## [씬 4] 20~32초 — 따라하기

```
🇰🇷 KO: "따라해 보세요."
[0.5초 간격]
🇺🇸 EN: "Repeat after me."
[0.7초 간격]

[집 — 1회]
🇰🇷 KO: "집"          [0.3초] → 🇺🇸 EN: "House"    [0.5초]
[집 — 2회]
🇰🇷 KO: "집"          [0.3초] → 🇺🇸 EN: "House"    [0.7초]

[회사 — 1회]
🇰🇷 KO: "회사"        [0.3초] → 🇺🇸 EN: "Company"  [0.5초]
[회사 — 2회]
🇰🇷 KO: "회사"        [0.3초] → 🇺🇸 EN: "Company"  [0.7초]

[화장실 — 1회]
🇰🇷 KO: "화장실"      [0.3초] → 🇺🇸 EN: "Bathroom" [0.5초]
[화장실 — 2회]
🇰🇷 KO: "화장실"      [0.3초] → 🇺🇸 EN: "Bathroom"
```

> 화면에는 각 단어의 한국어 + 로마자 + 영어가 함께 표시됨.
> **로마자는 오디오로 읽지 않음. 화면 표시만.**

---

## [씬 5 엔딩] 32~37초 — 고정 클립

```
🇰🇷 KO: "그럼 다음시간에 또 만나요."
(CTA 배너: "말모이랩에서 더 배우기 — malmoelab.com")

```
