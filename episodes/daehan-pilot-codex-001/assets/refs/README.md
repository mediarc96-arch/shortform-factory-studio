# Reference Frames

이 디렉터리는 씬 간 연속성을 위해 사용하는 참조 프레임을 둔다.

권장 파일:

- `shot-0-opening-exit.png`
- `shot-1-situation-exit.png`
- `shot-2-climax-exit.png`
- `shot-3-question-exit.png`
- `shot-4-reveal-repeat-exit.png`

규칙:

- 각 프레임은 해당 쇼트의 마지막 프레임이다.
- 다음 쇼트는 이 프레임을 느슨한 연속성 레퍼런스로 사용할 수 있다.
- 첫 프레임 완전 일치는 요구하지 않는다.
- 오프닝과 엔딩은 재사용 클립이므로 원본 비디오에서 직접 추출한다.
- `daehan-opening-clean-ref.jpg`는 현재 pilot의 기본 캐릭터 참조 이미지다.
- `daehan.jpg`는 두루마리 글자 때문에 생성 오염이 생겨, 현재 pilot scene 생성의 기본 참조로는 쓰지 않는다.
