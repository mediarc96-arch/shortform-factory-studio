## 구도 규칙 (핵심)

```
┌─────────────────────────────────────────────────────┐
│                                │                    │
│     칠판 영역                   │   선생님 캐릭터     │
│     (텍스트 오버레이 존)         │   (허리 위)        │
│                                │                    │
│     ← 프레임 왼쪽 65~70% →     │  ← 오른쪽 30~35% → │
│                                │                    │
└─────────────────────────────────────────────────────┘
```

- 카메라: 미디엄샷, 눈높이, 학생 책상 시점
- 칠판: 깨끗한 녹색 표면 (Grok은 텍스트 생성 금지)
- 텍스트: 전부 후편집에서 칠판 영역에 합성
- 레퍼런스: `docs/example/mBp3B.jpg` 구도 참고

## Grok 프롬프트 핵심 원칙

1. **구도 명시**: 모든 씬에 `"teacher on the RIGHT SIDE (30-35%), chalkboard on the LEFT (65-70%)"` 포함
2. **카메라 거리 명시**: `"medium shot, waist-up"` 항상 포함
3. **텍스트 금지**: `"Do NOT add any text, letters, numbers, subtitles, logos, or watermarks"` 항상 포함
4. **스타일 명시**: `"3D anime-style render"` 항상 포함
5. **레퍼런스 이미지**: `opening-ref.png` 를 항상 `image` 파라미터로 전달
6. **동작은 자연스럽게**: breathing, blinking, subtle sway 등 미세 동작 허용
