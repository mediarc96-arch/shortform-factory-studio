# Font Licenses

SFS Console uses a CSS font stack that prefers the Noto family when available on
the host or client system.

- Noto Sans
- Noto Sans KR
- Noto Sans JP
- Noto Sans SC
- Noto Sans Mono

These fonts are provided under the SIL Open Font License 1.1. The app does not
make runtime Google Fonts requests; if bundled font files are added later, keep
the same OFL-compatible family and record the exact file source here.

References:

- https://fonts.google.com/noto
- https://openfontlicense.org/
