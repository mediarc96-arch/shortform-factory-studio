# 참조 이미지 기반 쇼츠 워크플로우

이 작업공간은 `Shortform Factory`의 캐릭터 중심 쇼츠 및 단편 영상 제작을 위한 운영 루트입니다.

## 기본 원칙

처음에는 참조 이미지 기반 제작부터 시작합니다.

- 주인공을 정한다
- 캐노니컬 참조 이미지를 선별한다
- 쇼트 패킷을 만든다
- 키프레임 또는 스틸을 생성한다
- 이를 클립으로 확장한다
- 편집, QA, 고지, 게시까지 진행한다

반복되는 에피소드에서 참조 이미지 방식만으로는 동일 인물성이 충분히 유지되지 않을 때만 캐릭터 전용 LoRA나 유사 학습 방식으로 넘어갑니다.

## 에피소드별 필수 입력값

- 주인공 이름
- 캐릭터 바이블 경로
- 참조 폴더 경로
- 원본 이슈 ID
- 스타일 목표
- 출력 비율과 길이
- 고지 표시 위치
- 쇼트 리스트

## 반복 등장 캐릭터별 필수 항목

- `bible.md`
- `prompts.md`
- `refs/`
- 선택적 `lora/`
- 권리 메모

## 작업 폴더

- `characters/`
  - 반복 등장 주인공과 그 캐노니컬 자산
- `episodes/`
  - 에피소드별 패킷, 렌더, 최종 산출물
- `shared/`
  - 재사용 가능한 오버레이, 스타일, 음악, 효과음
- `inbound/references/`
  - 원본 참고 이미지 또는 승인된 외부 참조 드롭

## 제작 게이트

아래 항목 중 하나라도 빠져 있으면 에피소드를 생성 준비 완료 또는 게시 준비 완료로 표시하지 않습니다.

- 주인공
- 참조 경로
- 고지 위치
- 최종 파일 저장 계획
- QA 승인 요구사항

## Paperclip 이슈 운영

Paperclip에서는 새 에피소드와 기존 에피소드 수정을 명확히 구분해야 합니다.

- 새 에피소드 제작은 `new issue`
- 아직 게시되지 않은 기존 에피소드 수정은 기존 이슈의 `comment`
- 이미 게시된 영상을 다시 렌더하거나 다시 업로드해야 하면 `new issue`
- 제목, 설명, privacy 같은 메타데이터만 수정할 때는 기존 이슈의 `comment`

세부 규칙과 템플릿은 [PAPERCLIP_ISSUE_OPERATIONS.md](./PAPERCLIP_ISSUE_OPERATIONS.md)를 따른다.
