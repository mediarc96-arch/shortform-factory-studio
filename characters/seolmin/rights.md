# 설민 권리 메모

## 원본 자산

- 기준 이미지: `./Seolmin.png`
- 오프닝 자산: `./1_Opening_Seolmin.mp4`
- 인사 자산: `./1_Hello_Seolmin.mp4`

## 권리 상태

- 현재 상태: 사용자 제공 내부 프로젝트 자산으로 취급
- 내부 제작 범위 사용: 허용 전제
- 파생 작업: 내부 프로젝트 범위에서 생성, 편집, 애니메이션, 타이포 합성 허용 전제
- 외부 재배포: 최종 영상 산출물 공개 전 최종 확인 권장

## 운영 메모

- 현재 엔딩 자산은 없음
- 추가 참조 이미지나 엔딩 자산이 생기면 이 문서에 출처와 허용 범위를 같이 기록
- 외부 제작사 자산이 섞이는 경우 별도 권리 메모 추가
