# 설민 캐릭터 바이블

## 기본 정보

- 이름: 설민
- 역할: 한국어를 처음 배우는 시청자에게 밝고 귀엽게 설명해 주는 한글 선생님 캐릭터
- 포지션: 교실 칠판 앞에서 문장, 단어, 발음을 소개하는 메인 호스트
- 성격 키워드: 귀여움, 낙천적, 활발함, 친근함, 응원형 선생님

## 캐노니컬 외형

- 스타일: 2D 일러스트 기반의 chibi 비율 캐릭터
- 체형: 작은 몸과 큰 머리 비율의 귀여운 SD 스타일
- 얼굴: 둥글고 부드러운 인상, 큰 보라빛 눈, 항상 기분 좋은 미소
- 머리: 아주 밝은 백금색 계열의 긴 머리, 끝으로 갈수록 옅은 하늘색 그라데이션
- 의상: 검은 한복 계열 교사 복장, 흰 속깃과 흰색 매듭 포인트
- 모자: 전통 갓, 금빛 장식 띠, 양옆의 붉은 술 장식
- 액세서리: 작은 금빛 귀걸이
- 소품: 흰 분필
- 기본 배경 맥락: 녹색 칠판이 있는 따뜻한 교실

## 허용되는 변화

- 표정: 방긋 웃음, 기대하는 표정, 칭찬하는 표정, 놀란 듯한 리액션, 장난기 있는 윙크
- 포즈: 분필로 칠판을 가리키기, 칠판 쪽으로 손짓, 두 손을 모아 응원하기, 가볍게 손 흔들기
- 카메라: 정면, 3/4, 허리샷, 미디엄샷, 교육용 아이레벨 구도
- 프레이밍: 가로형 16:9 우선, 필요 시 세로형 9:16도 허용

## 금지되는 드리프트

- chibi 비율을 실사형이나 성인 비율로 바꾸지 말 것
- 머리색을 어둡게 바꾸지 말 것
- 보라빛 눈동자와 갓, 붉은 술 장식을 제거하지 말 것
- 검은 한복 계열 의상을 현대 교복이나 정장으로 바꾸지 말 것
- 공포 톤, 퇴폐적 톤, 과도하게 성숙한 연출 금지
- 칠판에 생성 단계에서 글자를 직접 넣지 말 것

## 연기와 톤

- 기본 톤: 명랑하고 통통 튀지만 과하게 산만하지 않은 교실 호스트
- 감정선: 늘 긍정적이고 시청자를 격려하는 방향
- 말투: 친절한 존댓말 중심, 필요할 때는 귀엽고 짧은 감탄을 섞을 수 있음
- 움직임: 작고 빠른 손동작, 고개 끄덕임, 발랄한 리듬감

## 운영 메모

- 설민은 대한보다 더 귀엽고 낙천적이며 활발한 방향으로 유지한다.
- 교육 화면에서는 칠판이 주 학습면이고, 설민은 칠판 오른쪽에서 안내하는 구도가 가장 안정적이다.
- 엔딩 자산이 없으므로 당분간 엔딩은 생성 또는 후반 합성 기준으로 운영한다.
